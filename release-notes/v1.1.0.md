## What's new

- Added prompts to save or discard unsaved edits before creating a document, opening another file, or exiting.
- Improved file error reporting and checked file reads, writes, and memory allocations.
- Added UTF-8 (with or without a BOM) and UTF-16 LE/BE input support, with a Windows ANSI code-page fallback for legacy text.
- Set a 16 MiB document size limit to keep memory use predictable.
- Fixed owner-drawn menu handling and cleaned up GDI and accelerator resources.
- Added Windows CI builds and automated release publishing.

Documents are saved as UTF-8 without a BOM. This release is a minimal single-document Notepad-style editor and does not preserve the source file's original encoding.
